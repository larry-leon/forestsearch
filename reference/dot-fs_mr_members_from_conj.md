# Row-index membership for one candidate conjunction.

Row-index membership for one candidate conjunction.

## Usage

``` r
.fs_mr_members_from_conj(df, cj)
```

## Arguments

- df:

  Analysis data frame.

- cj:

  Conjunction data frame with columns `variable`, `op`, `value`.

## Value

Integer row indices of subjects in the (harm) subgroup.
