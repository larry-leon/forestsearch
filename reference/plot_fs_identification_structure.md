# Composition of the identified subgroup by structure

Reproduces the supplement's stacked-composition figure.

## Usage

``` r
plot_fs_identification_structure(x, min_label = 0.03, palette = NULL)
```

## Arguments

- x:

  An `fs_identification` object.

- min_label:

  Numeric. Shares below this are drawn without a label.

- palette:

  Named character vector of fills, or `NULL` for the default.

## Value

A `ggplot` object.
