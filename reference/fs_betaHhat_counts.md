# Resolution counters from a `beta(Hhat)` table or attached results

Resolution counters from a `beta(Hhat)` table or attached results

## Usage

``` r
fs_betaHhat_counts(x)
```

## Arguments

- x:

  Output of
  [`fs_betaHhat_table()`](https://larry-leon.github.io/forestsearch/reference/fs_betaHhat_table.md)
  or
  [`fs_attach_betaHhat()`](https://larry-leon.github.io/forestsearch/reference/fs_attach_betaHhat.md).

## Value

A named list of counters, or `NULL` if none are attached.
