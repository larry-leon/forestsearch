# Print an MRCT case study

The four-set table and, when multiplier resampling ran on a declared
subgroup, the MR estimates and bounds for \\\hat H\\ and its non-region
complement \\\hat H^c\\.

## Usage

``` r
# S3 method for class 'mrct_case_study'
print(x, digits = 3, ...)
```

## Arguments

- x:

  An `mrct_case_study` object.

- digits:

  Digits for hazard ratios. Default 3.

- ...:

  Unused.

## Value

`x`, invisibly.
