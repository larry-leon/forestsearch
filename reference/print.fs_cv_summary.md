# Print Method for fs_cv_summary Objects

Print Method for fs_cv_summary Objects

## Usage

``` r
# S3 method for class 'fs_cv_summary'
print(x, n = 5L, ...)
```

## Arguments

- x:

  An `fs_cv_summary` object from
  [`summarize_cv_results`](https://larry-leon.github.io/forestsearch/reference/summarize_cv_results.md).

- n:

  Integer. Maximum rows to print from each raw data frame (default:
  `5L`).

- ...:

  Additional arguments (currently unused).

## Value

Invisibly returns `x`.
