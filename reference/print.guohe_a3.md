# Print method for guohe_a3 objects

Prints the family size, the selected candidate, the naive and de-biased
effects, and the three interval objects returned by
[`guohe_algorithm3()`](https://larry-leon.github.io/forestsearch/reference/guohe_algorithm3.md),
labelled by their status (Guo-He bound / extension / heuristic).

## Usage

``` r
# S3 method for class 'guohe_a3'
print(x, ...)
```

## Arguments

- x:

  An object of class `"guohe_a3"`.

- ...:

  Ignored; present for method consistency.

## Value

`x`, invisibly.
