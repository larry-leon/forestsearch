# Print method for guohe_ar objects

Prints the cross-validation objective over the `r` grid, marks the
selected value, and, when present, prints the refitted full-data
[`guohe_algorithm3()`](https://larry-leon.github.io/forestsearch/reference/guohe_algorithm3.md)
result.

## Usage

``` r
# S3 method for class 'guohe_ar'
print(x, ...)
```

## Arguments

- x:

  An object of class `"guohe_ar"`.

- ...:

  Ignored; present for method consistency.

## Value

`x`, invisibly.
