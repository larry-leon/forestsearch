`target_hr_harm` / `harm_z1_quantile` in `meta`). For the remaining 88 the recipe was rebuilt from
`meta` — `calibrate_k_inter(target_hr_harm, model = "alt", z1_quantile = harm_z1_quantile)` →
`setup_gbsg_dgm(n_super = 1e5, seed = 8316951)` → `simulate_from_dgm(n = n_sample, analysis_time = 84,
cens_adjust = log(1.5), seed = 8316951 + sim_id)`, as `sim_fs_maxeffCons_fb_mr_field_m1_template.qmd`
builds it (`:707`, `:736-746`, `:1007-1008`).

**The membership-size assertion failed.** Across the 88 bundles, 100 declared replicates each, the
recomputed |Ĥ| equalled the recorded `n_sel` on a median of **2.5 rows in 100** — chance agreement.
No bundle reproduced `n_sel` on all rows; five reproduced it on none.

Per the task's own rule, **a mismatch is a stop, not a number to report**: the regenerated data is a
different population from the one the run used, so its per-arm event counts say nothing about the
committed results. Counts were computed and are **deliberately withheld** rather than presented as
evidence. The binary path's assertion passing 3313/3313 on the same machinery is what separates a
genuine reconstruction from this one.

What the reconstruction is missing is not identified here — diagnosing it is a task, not a finding.
The plausible candidates, in order, are (i) the super-population depends on RNG state at the moment
`setup_gbsg_dgm()` is called and the template's call site sits at a different point in the stream
than this script's, and (ii) the noise-covariate draw at `seed_base + sim_id + 1000000L`
(template `:1024`) intervenes between replicates in the run and not here. Note that (i) is the exact
shape of the correction the admission check already recorded for the binary path — that finding
generalises, and the survival path evidently has its own instance of it.

## 3. The residual assumption, stated

This checks **declared** subgroups only — the Ĥ each replicate reported and its complement. A
candidate that was **admitted but not selected**, and on which the estimand did not exist, is not
visible here: the recorded artefacts carry the declared `sg_def`, not the admitted family.

The reason the declared check is nevertheless the right instrument is the selection rule: under
neighbourhood selection a divergent effect estimate would have dominated its neighbourhood and been
declared, so a non-estimable candidate that mattered to the outcome would appear as the declared Ĥ
and be caught above. That is an argument about where a divergent estimate *goes*, not a proof that no
such candidate was ever admitted. **It is not claimed that no committed run ever admitted a
non-estimable candidate** — only that none was declared, in the campaigns checked.

A second, narrower residual: §1a's blocks are Ĥ and Ĥᶜ as declared. The oracle refits on the *true*
region, which is not a candidate and is governed only by the study's pooled 5-events/5-non-events
guard; it is outside the scope of both the boundary rule as described and this check.
