Operating Characteristics of Multiplier Resampling (MR)

Estimation/coverage head-to-head against the full bootstrap (FB), on the León (2024) Table 2 design

Author

Larry León

Published

July 31, 2026

Status — smoke test. This is the development configuration of the simulation: tiny counts to wire the pipeline end-to-end on a single M1 cell before scaling up. Every tunable lives in the setup chunk (Section 2); the counts (n_sims, nb_boots, mr_draws) are the main knobs for moving from smoke test to production; run_mode and sim_id_start (Section 2) split a long run into seed-disjoint batches that combine later. Each batch render persists its results to an .rds; run_mode = "combine" reads them back and renders every table on the pooled set.

1 What this evaluates

Multiplier resampling (MR) (fs_mr_inference(), surfaced through forestsearch(mr_inference = TRUE)) is a refit-free multiplier-bootstrap approximation of León’s post-selection bias correction, with an infinitesimal-jackknife (IJ) confidence interval. To first order its point estimate equals León’s Eq. 7 correction and its interval equals León’s IJ variance, the only approximation being the per-subgroup dfbeta linearization.

This document turns the single-trial validation into operating characteristics by re-running the León (2024) estimation/coverage design and recording, per replicate on the same data and the same selected subgroup:

  • oracle \(\hat\theta(H)\) — refit on the true harm subgroup;
  • naive \(\hat\theta(\hat H)\) — plugin on the identified subgroup;
  • FB \(\hat\theta^{*}(\hat H)\) — full nonparametric bootstrap bias-correction (forestsearch_bootstrap_dofuture(), León Eq. 7, the H2 variant accounting for both bias sources) with its IJ interval;
  • MR \(\tilde\theta(\hat H)\) — refit-free multiplier resampling, holding the fitted candidate family fixed, with its IJ interval.

Each is compared to three truth targets: the per-replicate oracle estimate, the controlled direct effect \(\theta^{\ddagger}\) (CDE), and the marginal subgroup hazard ratio \(\theta^{\dagger}\). The two outputs are (1) the León Table-2-layout estimation/coverage table with an MR block, and (2) the paired FB\(\leftrightarrow\)MR agreement panel. For consistency (a fixed candidate family) that panel is the most direct empirical check of the leading-order correspondence; for dina/grf the bootstrap regenerates the family per resample, so the panel instead measures the family-regeneration gap between the unconditional (FB) and conditional-on-family (MR) estimands.

The search runs under consistency_method = "resample" and sg_focus = "maxcons" — the consistency argmax: highest consistency rate, ties broken by effect. MR de-biases against that same candidate family, using the rule forestsearch() derives from sg_focus rather than one set here, so FB and MR share the same selection map. MR does not identify a subgroup; the one reported is the one the search selected.

4 Per-replicate paired recorder

For each simulated trial: identify \(\hat H\) and obtain the naive + MR in one forestsearch() call, run the FB bootstrap on the same fit (inheriting consistency_method = "resample"), and refit the oracle on the true subgroup. # Cox HR + delta-method 95% CI on a subset (for the per-replicate oracle).
# Guards against separation: non-finite coef/SE (the "coefficient may be
# infinite" case) returns a clean NA triple rather than Inf/NaN bounds.
.cox_hr_ci <- function(df) {
  if (sum(df[[event_name]]) < 5L || length(unique(df[[treat_name]])) < 2L)
    return(c(est = NA_real_, lo = NA_real_, hi = NA_real_, se = NA_real_))
  fml <- stats::as.formula(
    sprintf("survival::Surv(%s, %s) ~ %s", outcome_name, event_name, treat_name))
  fit <- tryCatch(survival::coxph(fml, data = df), error = function(e) NULL)
  if (is.null(fit)) return(c(est = NA_real_, lo = NA_real_, hi = NA_real_, se = NA_real_))
  b  <- unname(stats::coef(fit)[1])
  v  <- unname(suppressWarnings(diag(stats::vcov(fit))[1]))  # unname: else lo/hi inherit coef name -> oH["lo"] = NA
  se <- if (is.finite(v) && v > 0) sqrt(v) else NA_real_
  if (!is.finite(b) || !is.finite(se))
    return(c(est = NA_real_, lo = NA_real_, hi = NA_real_, se = NA_real_))
  c(est = exp(b), lo = exp(b - z975 * se), hi = exp(b + z975 * se), se = se)
}

# Recover the log-HR (beta-scale) SE from an HR-scale SD: sd_hr = HR * se_beta,
# so se_beta = sd_hr / HR.  Used for the FB row, whose bootstrap summary reports
# sdH2 on the HR scale.  Returns NA on a non-positive/non-finite estimate.
.se_beta_hr <- function(sd_hr, hr) {
  if (is.finite(sd_hr) && is.finite(hr) && hr > 0) sd_hr / hr else NA_real_
}

# Classification of the identified subgroup against the true harm flag.
# sg_hat is grp.consistency$sg.harm.id: a per-subject 0/1 vector, length
# nrow(df), aligned to the input rows (clean on the consistency result; the
# GRF-object naming collision does not apply here).
.classify <- function(sg_hat, truth) {
  out <- c(sens = NA_real_, spec = NA_real_, ppv = NA_real_, npv = NA_real_)
  if (is.null(sg_hat) || length(sg_hat) != length(truth)) return(out)
  sg_hat <- as.integer(sg_hat); truth <- as.integer(truth)
  tp <- sum(sg_hat == 1 & truth == 1); fp <- sum(sg_hat == 1 & truth == 0)
  fn <- sum(sg_hat == 0 & truth == 1); tn <- sum(sg_hat == 0 & truth == 0)
  out["sens"] <- if (tp + fn > 0) tp / (tp + fn) else NA_real_
  out["spec"] <- if (tn + fp > 0) tn / (tn + fp) else NA_real_
  out["ppv"]  <- if (tp + fp > 0) tp / (tp + fp) else NA_real_
  out["npv"]  <- if (tn + fn > 0) tn / (tn + fn) else NA_real_
  out
}

record_replicate <- function(sim_id) {
  rec <- .na_record(sim_id)

  df <- tryCatch(
    simulate_from_dgm(dgm, n = n_sample, analysis_time = analysis_time,
                      cens_adjust = cens_adjust, seed = seed_base + sim_id),
    error = function(e) NULL)
  if (is.null(df)) return(rec)
  df[[id_name]] <- seq_len(nrow(df))
  
  confs <- intersect(confounders_base, names(df))

# Add k_random_noise standard-normal noise covariates
# (k_random_noise is set upstream, e.g. in the setup chunk; 0 = no noise)
if (k_random_noise > 0) {
  noise_names <- paste0("noise", seq_len(k_random_noise))
  # Seed the noise draws by sim_id (offset to stay disjoint from the DGM seed
  # seed_base + sim_id) so the FULL replicate -- survival data AND noise -- is a
  # deterministic function of sim_id, independent of batch and loop position.
  # Without this the noise would draw from future's per-iteration RNG stream,
  # which is keyed to loop position, not sim_id, and could collide across batches.
  set.seed(seed_base + sim_id + 1000000L)
  for (nm in noise_names) {
    df[[nm]] <- rnorm(n = nrow(df))
  }
  confs <- c(confs, noise_names)
}
  
  
  rec$n_true <- sum(df[[harm_col]] == 1L, na.rm = TRUE)   # true |Q| this trial (all reps)

  # For "consistency" the family is fixed, so FB and the MR target
  # the same estimand; for "dina"/"grf" the family regenerates per resample, so
  # FB is the *unconditional* comparator against MR's
  # *conditional-on-family* estimate -- a FB<->MR gap there is the

  # call falls back to NULL (fb_* stay NA) and the message is captured in fb_err.

      forestsearch_bootstrap_dofuture(
        fs.est, nb_boots = nb_boots, seed = seed_base + sim_id,
        parallel_args = inner_parallel,

        # mr_inference = TRUE, and the replicate call is a copy of that fit's
        # argument list, so without this the flag would be inherited and MR
        # would run inside all nb_boots replicates of every sim.  Nothing
        # downstream consumes a per-replicate MR object.  No-op as written.

      # %||% guards a missing H2 column (get_dfRes omits H2 when the 2nd-order
      # bias adjustment is unavailable): a bare NULL assignment would DELETE the
      # column from rec, and the short record is then silently dropped by the
      # run-loop's rbind/.errorhandling = "remove" -> a hidden, non-random loss.
      rec$fb_H_est <- he$H2 %||% NA_real_
      rec$fb_H_lo  <- he$H2_lower %||% NA_real_
      rec$fb_H_hi  <- he$H2_upper %||% NA_real_
      rec$fb_H_se  <- .se_beta_hr(he$sdH2 %||% NA_real_, he$H2 %||% NA_real_)
    }
    if (!is.null(boot) && !is.null(boot$Hc_estimates)) {
      hce <- boot$Hc_estimates
      rec$fb_Hc_est <- hce$H2 %||% NA_real_
      rec$fb_Hc_lo  <- hce$H2_lower %||% NA_real_
      rec$fb_Hc_hi  <- hce$H2_upper %||% NA_real_
      rec$fb_Hc_se  <- .se_beta_hr(hce$sdH2 %||% NA_real_, hce$H2 %||% NA_real_)
    }
  }

  # ---- Oracle: refit on the TRUE harm subgroup of this trial ---------------
  oH  <- .cox_hr_ci(df[df[[harm_col]] == 1, , drop = FALSE])
  oHc <- .cox_hr_ci(df[df[[harm_col]] == 0, , drop = FALSE])
  rec$or_H_est <- oH["est"];   rec$or_H_lo <- oH["lo"];   rec$or_H_hi <- oH["hi"];   rec$or_H_se <- oH["se"]
  rec$or_Hc_est <- oHc["est"]; rec$or_Hc_lo <- oHc["lo"]; rec$or_Hc_hi <- oHc["hi"]; rec$or_Hc_se <- oHc["se"]

  rec

6 Timing and scale-up projection

MR cost per replicate is essentially fixed (one fit + the multiplier draws, independent of nb_boots); FB cost scales linearly with nb_boots (it re-runs the whole search once per bootstrap). The projection below uses the measured per-replicate times and assumes FB runs only on detected replicates. The modelled wall-clock spreads the reps over the workers respecting the integer reps-per-worker ceiling, then a single calibration factor (measured wall / modelled wall on this run) carries this run’s realized overhead into the projections.

    h <- floor(sec / 3600); m <- round((sec - 3600 * h) / 60)

  #             (parallel) bootstrap time.

# All summaries are finite-only: non-finite estimates/bounds (e.g. from Cox
# separation or an unstable small-B IJ) are dropped so a single blow-up cannot
# dominate a mean.
.cover <- function(target, lo, hi) {
  target <- rep_len(target, length(lo))   # recycle scalar targets (CDE/marginal) to n reps
  ok <- is.finite(target) & is.finite(lo) & is.finite(hi)
  if (!any(ok)) return(NA_real_)
  mean(target[ok] >= lo[ok] & target[ok] <= hi[ok])
}
.pbias <- function(est, target) {
  d <- (est - target) / target; d <- d[is.finite(d)]
  if (!length(d)) return(NA_real_)
  100 * mean(d)
}
.mfin <- function(x) { x <- x[is.finite(x)]; if (length(x)) mean(x) else NA_real_ }
.sdfin <- function(x) { x <- x[is.finite(x)]; if (length(x) > 1L) sd(x) else NA_real_ }
# Empirical (true) SD on the log-HR (beta) scale: SD of log(HR) across reps.
.sd_log <- function(e) { l <- log(e[is.finite(e) & e > 0]); if (length(l) > 1L) sd(l) else NA_real_ }
# Stored per-replicate log-HR (beta-scale) SE for an estimator -- read at the
# source, never back-calculated from CI bounds (or_/nv_/fb_*_se; MR uses its IJ
# SE, mr_*_se_ij).  A missing column (results saved before SEs were stored)
# yields all-NA so the table still renders.
.get_se <- function(r, k, suffix) {
  col <- if (k == "mr") paste0(k, "_", suffix, "_se_ij") else paste0(k, "_", suffix, "_se")
  v <- r[[col]]
  if (is.null(v)) rep(NA_real_, nrow(r)) else v
}

# Build one block (H or Hc): four estimator rows against three targets.
build_block <- function(r, suffix, tgt_cde, tgt_marg) {
  est_keys <- c(oracle = "or", naive = "nv", FB = "fb", MR = "mr")
  if (!run_fb) est_keys <- est_keys[names(est_keys) != "FB"]  # MR-only run
  or_est <- r[[paste0("or_", suffix, "_est")]]   # per-replicate oracle target
  bH_est <- r[[paste0("betaHhat_", suffix)]]     # per-replicate beta(Hhat) target
  rows <- lapply(names(est_keys), function(lab) {
    k  <- est_keys[[lab]]
    e  <- r[[paste0(k, "_", suffix, "_est")]]
    lo <- r[[paste0(k, "_", suffix, "_lo")]]
    hi <- r[[paste0(k, "_", suffix, "_hi")]]
    len <- hi - lo; len <- len[is.finite(len)]
    seb <- .get_se(r, k, suffix)                  # stored log-HR (beta) SE
    data.frame(
      Estimator = lab,
      n       = sum(is.finite(e)),
      Avg     = .mfin(e),
      SD        = .sd_log(e),                      # empirical SD, log-HR (beta) scale  [reported]
      SD_hr     = .sdfin(e),                       # empirical SD, HR scale             [retained]
      SD_hat    = .mfin(seb),                      # mean model SE, log-HR (beta) scale [reported]
      SD_hat_hr = .mfin(e * seb),                  # mean model SE, HR scale            [retained]
      Len_med = if (length(len)) stats::median(len) else NA_real_,
      Length  = if (length(len)) mean(len) else NA_real_,
      b_oracle = .pbias(e, or_est),
      b_betaHhat = .pbias(e, bH_est),
      b_cde    = .pbias(e, tgt_cde),
      b_marg   = .pbias(e, tgt_marg),
      Cov_oracle = .cover(or_est, lo, hi),
      Cov_betaHhat = .cover(bH_est, lo, hi),
      Cov_cde    = .cover(tgt_cde,  lo, hi),
      Cov_marg   = .cover(tgt_marg, lo, hi),
      stringsAsFactors = FALSE)
  })
  do.call(rbind, rows)
}
