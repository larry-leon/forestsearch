Cross-cut Summary: sg_focus × FS Bundle (ACTG175 Binary, m1)

This article compares operating characteristics across the cross-product of sg_focus and FS parameter bundle for a fixed study × outcome × DGM × objective combination:

  • study : ACTG175
  • outcome : binary
  • DGM : m1 (calibrated GLM, target OR(Q) = 2.0)
  • objective : harm
  • varied : sg_focus (e.g., hr, hrMaxSG, maxSG) × FS bundle (fs*)

Each cell of the grid corresponds to one bundle file produced by its companion runner script. The full intended grid is declared below; missing bundles are skipped with a message (set strict_bundles <- TRUE in setup to error instead).

Unified H1 Operating Characteristics

A single combined table with one row per (config × analysis method). FS rows are grouped by sg_focus × fs so detection, classification, and effect estimates can be compared across sg_focus criteria.

GRF does not depend on sg_focus (its results are invariant across the focus criteria), so a single GRF row is shown at the end of the table under its own group rather than redundantly within each focus group.

The DGM truth (target OR, true subgroup, prevalence) is fixed across all configurations and shown once in the table subtitle, rather than repeated per cell.

# Use the first available bundle's calibrated DGM as the reference.
ref_dgm <- bundles[[1]]$dgm$calibrated
or_target_H  <- ref_dgm$hazard_ratios$harm_subgroup
or_target_Hc <- ref_dgm$hazard_ratios$no_harm_subgroup
or_target_ITT <- ref_dgm$hazard_ratios$overall

# -- Helper: conditional trimmed mean ----------------------------------------
# Returns a list with the chosen mean (raw or trimmed) and a flag
# indicating whether trimming was applied. The rule is the mean-vs-median
# ratio: if |mean - median| / |median| exceeds the threshold, the mean
# is being pulled by extreme values and we report a trimmed mean.
# Otherwise the raw mean is returned (preserving "on average" reading).
cond_trim_mean <- function(x,
                           threshold = or_trim_threshold,
                           trim      = or_trim,
                           na.rm     = TRUE) {
  x_clean <- if (na.rm) x[!is.na(x)] else x
  if (length(x_clean) == 0L) {
    return(list(value = NA_real_, trimmed = FALSE))
  }
  mu  <- mean(x_clean)
  med <- stats::median(x_clean)
  # Avoid division by zero / sign issues; require a meaningful median
  if (is.na(med) || med == 0 || !is.finite(med)) {
    return(list(value = mu, trimmed = FALSE))
  }
  if (abs(mu - med) / abs(med) > threshold) {
    list(value = mean(x_clean, trim = trim), trimmed = TRUE)
  } else {
    list(value = mu, trimmed = FALSE)
  }
}

# Compute the same summary statistics format_oc_results() does, but
# combined across all configurations into one long data.frame.
oc_rows <- data.table::rbindlist(lapply(seq_len(nrow(configs)), function(i) {
  b <- bundles[[i]]
  res <- b$results$alt
  if (is.null(res) || nrow(res) == 0L) return(NULL)
  dt <- data.table::as.data.table(res)

  per_analysis <- lapply(unique(dt$analysis), function(a) {
    r       <- dt[analysis == a]
    r_found <- r[any.H == 1L]
    n_sims  <- length(unique(r$sim))

    # Conditional trimming applied to the three OR estimates
    or_h_hat   <- if (nrow(r_found)) cond_trim_mean(r_found$hr.H.hat)  else list(value = NA_real_, trimmed = FALSE)
    or_hc_hat  <- if (nrow(r_found)) cond_trim_mean(r_found$hr.Hc.hat) else list(value = NA_real_, trimmed = FALSE)
    or_itt     <- cond_trim_mean(r$hr.itt)

    list(
      group              = sprintf("%s × %s", configs$focus[i], configs$fs[i]),
      Analysis           = a,
      N_sims             = n_sims,
      Detection          = mean(r$any.H == 1L, na.rm = TRUE),
      Sen                = mean(r$sens, na.rm = TRUE),
      Spec               = mean(r$spec, na.rm = TRUE),
      PPV                = mean(r$ppv, na.rm = TRUE),
      NPV                = mean(r$npv, na.rm = TRUE),
      OR_H_hat           = or_h_hat$value,
      OR_H_trimmed       = or_h_hat$trimmed,
      OR_Hc_hat          = or_hc_hat$value,
      OR_Hc_trimmed      = or_hc_hat$trimmed,
      OR_ITT             = or_itt$value,
      OR_ITT_trimmed     = or_itt$trimmed,
      Size_H_mean        = if (nrow(r_found)) mean(r_found$size.H, na.rm = TRUE) else NA_real_,
      Size_H_min         = if (nrow(r_found)) min(r_found$size.H,  na.rm = TRUE) else NA_integer_,
      Size_H_max         = if (nrow(r_found)) max(r_found$size.H,  na.rm = TRUE) else NA_integer_
    )
  })
  data.table::rbindlist(per_analysis)
}))

# -- Collapse redundant GRF rows -----------------------------------------
# GRF does not depend on sg_focus, so its results are identical across
# the focus groups. We collapse the redundant rows into a single GRF
# row at the end of the table, displayed under its own group.
#
# Sanity check: warn if GRF metrics actually differ across focus groups,
# which would suggest a bundle inconsistency rather than a true GRF
# invariance.
grf_rows <- oc_rows[Analysis == "GRF"]
if (nrow(grf_rows) > 1L) {
  metric_cols <- c("Detection", "Sen", "Spec", "PPV", "NPV",
                   "OR_H_hat", "OR_Hc_hat", "OR_ITT",
                   "Size_H_mean", "Size_H_min", "Size_H_max")
  # Check (within tolerance for floating point)
  inconsistent <- vapply(metric_cols, function(col) {
    vals <- grf_rows[[col]]
    vals <- vals[!is.na(vals)]
    if (length(vals) <= 1L) return(FALSE)
    diff_range <- max(vals) - min(vals)
    # Tolerance: 1e-8 absolute or 1e-6 relative to median
    abs_med <- abs(stats::median(vals))
    diff_range > max(1e-8, 1e-6 * abs_med)
  }, logical(1))
  if (any(inconsistent)) {
    warning(sprintf(
      "GRF rows differ across focus groups in column(s): %s. Collapsing anyway using the first focus group's values; investigate if unexpected.",
      paste(names(which(inconsistent)), collapse = ", ")
    ), call. = FALSE)
  }
}

# Keep one GRF row (relabel its group), drop the rest, append at end
if (nrow(grf_rows) > 0L) {
  one_grf <- grf_rows[1L]
  one_grf[, group := "GRF (sg_focus-invariant)"]
  oc_rows <- rbind(
    oc_rows[Analysis != "GRF"],
    one_grf
  )
  # Re-establish factor levels so the GRF group sorts to the end
  fs_grp_levels <- sprintf("%s × %s", configs$focus, configs$fs)
  oc_rows[, group := factor(group,
                            levels = c(fs_grp_levels,
                                       "GRF (sg_focus-invariant)"))]
  data.table::setorder(oc_rows, group, Analysis)
}

Notes

  • This article assumes all bundles share the same DGM truth (study × outcome × DGM × objective). Cross-cuts that vary the DGM need a different summary template (with per-bundle reference values for target OR, true |Q|, etc.).
  • The unified H1 OC table reports raw means (mean(...)) for each OR estimate by default — preserving the standard “on average” interpretation. When the |mean − median|/|median| ratio for a given OR exceeds or_trim_threshold (default 0.20), the raw mean is being pulled by extreme values; in those cells the table reports a trimmed mean (default 5% from each tail) and flags the row in the Trim column. The threshold and trim level are configurable in the setup chunk; the Trim column is hidden entirely when no cell needed trimming.
  • GRF rows are collapsed: GRF does not depend on sg_focus, so its results are identical across the five focus groups. The table shows GRF once, at the end, under its own group. A consistency check warns if the GRF rows actually differ across focus groups (which would indicate a bundle issue rather than true invariance).
  • The grouped classification tables (one per analysis method) use build_classification_table() with all configurations passed as scenarios in a single call — producing one table per analysis method with row groups per sg_focus × fs cell.
  • Toggle strict_bundles <- TRUE in setup to fail when any cell in the declared grid is missing — useful as a completeness check once all configurations are expected to be built.
